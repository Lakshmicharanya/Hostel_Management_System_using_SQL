# 🏨 Hostel Management System

A database-driven Hostel Management System developed using **SQL and MySQL** to manage hostel information efficiently.

## 📌 Project Description

The system helps manage student records, room details, room allocations, fees, and complaints in a centralized database. It reduces manual work and makes hostel data easier to store, update, and retrieve.

## 🛠️ Technologies Used

* **Database:** MySQL
* **Language:** SQL
* **Tool:** MySQL Workbench

## ✨ Features

* Student Management
* Room Management
* Room Allocation
* Fee Management
* Complaint Management
* User Management
* SQL Queries for data retrieval and analysis
* Primary Keys and Foreign Keys for maintaining relationships

## 📂 Database Tables

The project includes tables for managing:

* Users
* Students
* Rooms
* Room Allocations
* Fees
* Complaints

## 🚀 How to Run

1. Install **MySQL Server** and **MySQL Workbench**.
2. Open the `Hostel_Management_System.sql` file in MySQL Workbench.
3. Execute the SQL script.
4. The database and required tables will be created.
5. Use SQL queries to insert, update, delete, and retrieve data.

## 🎯 Objective

The main objective of this project is to provide an organized database system for managing hostel records and reducing errors associated with manual record management.
